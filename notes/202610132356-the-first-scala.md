# The first Scala

"This was my first project using Scala language, at UFRJ, with 2 more friends".

The arc gained a mark for 2017: [h0ffmann/mdd-risk-analysis](https://github.com/h0ffmann/mdd-risk-analysis),
a course project on risk analysis with Apache Spark. The record shows the repository: made on
18 April 2017, R and Scala, Spark 2.1.0, the work done by the end of June 2017. That it was the
first Scala, and that Scala was learned there, is the owner's word.

It stands between the laboratory and Stone because it is the bridge between them: the language
learned in a course is the language of the first job. Nobody else is named on this page. The
whole story, with its people, is in four notes of the book,
[closed source](https://github.com/h0ffmann/closed-source/tree/main/notes), under "the first
Scala, and Marcus Baffa".
