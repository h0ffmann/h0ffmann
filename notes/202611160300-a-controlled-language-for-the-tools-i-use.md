# A Controlled Language for the Tools I Use

Date: 2026-11-16
Status: Verified

Adopted ASD-STE100 (Issue 9) rules for project documentation and posts.
Structural rules (max 25 words/sentence, max 6 sentences/paragraph) are strictly enforced via `snippets-check.py` and manual review.
Lexical rules are advisory outside strict technical documents.
This ensures clarity and reduces ambiguity in open-source tooling.
